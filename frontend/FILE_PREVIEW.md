# معاينة ملفات المشاريع داخل الموقع

أُضيف زر **معاينة** إلى جدول الملفات في صفحة المشروع. تفتح المعاينة داخل نافذة
في الموقع دون الحاجة إلى تنزيل الملف على القرص أولًا. زر التنزيل الأصلي ما زال متاحًا.

## الأنواع المدعومة

- PDF: عرض داخل عارض المتصفح.
- PNG/JPG/GIF/WebP/BMP/AVIF: معاينة صور (بحسب دعم المتصفح).
- MP3/WAV/FLAC/M4A وMP4/WebM/MOV: مشغّل وسائط HTML5 (بحسب دعم المتصفح والترميز).
- TXT/CSV/MD/JSON/XML/SQL/HTML/SVG: معاينة **نصية** غير تنفيذية، ولا يتم تشغيل HTML أو SVG.
- DOCX/XLSX/PPTX: استخراج **النص فقط** من المستند على الخادم؛ لا تُحافظ المعاينة على تنسيق Office أو الصور والتخطيطات. يُسمح بملفات Office حتى 20 ميغابايت ويُختصر النص المستخرج إلى 120,000 حرف.

الأنواع الأخرى مثل DOC/XLS/PPT القديمة، HEIC/TIFF، الأرشيفات، وملفات CAD غير مدعومة في هذا الإصدار؛ يظهر خيار تنزيل الملف.

## الأمان والتنفيذ

- يستخدم المسار `GET /api/v1/files/{id}/preview` نفس مصادقة JWT وفحوص الوصول إلى المشروع والملف الموجودة في مسار التنزيل.
- لا يخرج رابط مباشر من MinIO إلى المتصفح، ولا تُرسل الوثائق إلى خادم طرف ثالث.
- يُطابق الخادم نوع MIME الذي تحقق منه وقت رفع الملف مع امتداده قبل عرضه، ويمنع المعاينة للأنواع غير المعروفة.
- تُعرض ملفات HTML وSVG كنص عادي وليس كمحتوى نشط.
- تستخدم الاستجابة `no-store` و`nosniff`، وتُحمّل الواجهة معاينة الملف إلى Object URL مؤقت يُلغى عند الإغلاق.
- يمنع العميل معاينة ملفات ثنائية أكبر من 75 ميغابايت عبر النافذة، لكن مسار التنزيل الأصلي يبقى متاحًا.

## اختبارات المتابعة

اختبارات وحدة لأنواع MIME: `FilePreviewServiceTest`.
ينبغي تنفيذ `mvnw.cmd test` و`npm run typecheck` و`npm run build` ومراجعة سيناريوهات منع الوصول وملفات Office غير السليمة قبل الدمج في `main`.

## إصلاح PDF وMP4 (نوفمبر 2026)

- يعيد مسار المعاينة الآن `ResponseEntity<StreamingResponseBody>` بشكل صريح، ليتعرف Spring MVC على البث بدل محاولة تحويله ككائن JSON.
- يدعم الخادم لوسائط الصوت والفيديو طلب `Range: bytes=...` مع `206 Partial Content` و`Content-Range` و`Accept-Ranges`.
- يقرأ MinIO نطاق البايتات المطلوب مباشرة بدل تنزيل الوسائط كاملة في كل طلب.
- تمرر بوابة Next.js ترويسة `Range` وترويسات الاستجابة المتعلقة بالنطاقات.
- يستخدم مشغل الوسائط داخل النافذة عنوان البوابة الآمن مباشرة، بينما تستمر معاينة PDF بالـBlob المؤقت.
- تمت إضافة `FilePreviewByteRangeTest` لحالات النطاق المفتوح والمغلق والخاطئ.

**ملاحظة:** تشغيل MP4 داخل المتصفح يتطلب أيضًا ترميز فيديو/صوت متوافقًا مع المتصفح (مثل H.264/AAC). الامتداد وحده لا يضمن إمكانية تشغيله. لم تُشغّل الاختبارات الآلية في بيئة هذه الجلسة.


## تحسين أنواع الملفات وOffice (15 نوفمبر 2026)

- يدعم عارض الصور أزرار التكبير والتصغير وإعادة الضبط. صور JPEG/PNG/GIF/WebP/BMP/AVIF تمر عبر مسار المعاينة المحمي.
- يعرض DOCX الفقرات والعناوين والخط العريض والمائل والتسطير والجداول بصورة تقريبية داخل صفحة ذات عرض مناسب.
- يعرض XLSX في جدول بأرقام صفوف وعناوين أعمدة، مع التبديل بين أوراق العمل وتنسيق القيم المعروضة.
- يعرض PPTX نص الشرائح على شكل بطاقات، وليس كامل تخطيط PowerPoint.
- أصبحت معاينة Office تستخدم `GET /api/v1/files/{id}/preview/office` (JSON منظم) ويُعرض المحتوى بواسطة React كنص مهرب. لا يعيد الخادم مستند HTML حرًّا من محتوى المستخدم.
- تشمل القيود: 20 MiB لملف Office المضغوط، و120 ألف حرف، و250 كتلة Word، و80 صفًا/20 عمودًا لكل جدول Word، و8 أوراق Excel/150 صفًا/30 عمودًا، و60 شريحة PowerPoint.
- تمت معالجة رابط الصوت الفارغ. يجري بث الصوت والفيديو باستخدام الرابط المحمي ونطاقات البايت.
- الامتدادات غير المدعومة مثل DOC/XLS/PPT القديمة وTIFF/HEIC وملفات CAD والأرشيفات تظهر تنزيلًا آمنًا، وليس معاينة متوهمة.

### ملاحظات التشغيل

إن نجاح فحص الأنواع لا يكفي لإثبات دعم كل ترميز. قد لا يدعم المتصفح صور AVIF أو ملفات MOV/MP4 ذات ترميز غير شائع. PDF قد يخضع لسياسات عرض ملفات PDF في المتصفح. استخدم تحديث Docker الكامل لتجربة نسخة الواجهة والباك الجديدة معًا، لأن إضافة endpoint Office تتطلب تحديث الخادم أيضًا.
