# معاينة ملفات المشاريع داخل الموقع

أُضيف زر **معاينة** إلى جدول الملفات في صفحة المشروع. تفتح المعاينة داخل نافذة
في الموقع دون الحاجة إلى تنزيل الملف على القرص أولًا. زر التنزيل الأصلي ما زال متاحًا.

## الأنواع المدعومة

- PDF: عرض داخل عارض المتصفح.
- PNG/JPG/GIF/WebP/BMP/AVIF: معاينة صور (بحسب دعم المتصفح).
- MP3/WAV/FLAC/M4A وMP4/WebM/MOV: مشغّل وسائط HTML5 (بحسب دعم المتصفح والترميز).
- TXT/CSV/MD/JSON/XML/SQL/HTML/SVG: معاينة **نصية** غير تنفيذية، ولا يتم تشغيل HTML أو SVG.
- DOCX/XLSX/PPTX: استخراج **النص فقط** من المستند على الخادم؛ لا تُحافظ المعاينة على تنسيق Office أو الصور والتخطيطات. يُسمح بملفات Office حتى 20 ميغابايت ويُختصر النص المستخرج إلى 120,000 حرف.

الأنواع الأخرى مثل DOC/XLS/PPT القديمة، HEIC/TIFF، الأرشيفات، وملفات CAD غير مدعومة في هذا الإصدار؛ يظهر خيار تنزيل الملف.

## الأمان والتنفيذ

- يستخدم المسار `GET /api/v1/files/{id}/preview` نفس مصادقة JWT وفحوص الوصول إلى المشروع والملف الموجودة في مسار التنزيل.
- لا يخرج رابط مباشر من MinIO إلى المتصفح، ولا تُرسل الوثائق إلى خادم طرف ثالث.
- يُطابق الخادم نوع MIME الذي تحقق منه وقت رفع الملف مع امتداده قبل عرضه، ويمنع المعاينة للأنواع غير المعروفة.
- تُعرض ملفات HTML وSVG كنص عادي وليس كمحتوى نشط.
- تستخدم الاستجابة `no-store` و`nosniff`، وتُحمّل الواجهة معاينة الملف إلى Object URL مؤقت يُلغى عند الإغلاق.
- يمنع العميل معاينة ملفات ثنائية أكبر من 75 ميغابايت عبر النافذة، لكن مسار التنزيل الأصلي يبقى متاحًا.

## اختبارات المتابعة

اختبارات وحدة لأنواع MIME: `FilePreviewServiceTest`.
ينبغي تنفيذ `mvnw.cmd test` و`npm run typecheck` و`npm run build` ومراجعة سيناريوهات منع الوصول وملفات Office غير السليمة قبل الدمج في `main`.
